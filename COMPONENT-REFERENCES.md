# My Car Atlas — component reference inventory

This project is inspired by **my own 2024 BMW X5 40i M-Sport (G05 LCI)**. The sources below guide its educational reconstruction.

The exterior adapts BMW’s CC BY 4.0 G05 model for the **G05 LCI M Sport**. Mechanical parts remain illustrative; none of these references establishes VIN-specific CAD. See [body provenance](dist/models/README.md).

The engine targets **B58N / B58B30M2**, identified for the LCI 40i in [BMW service bulletin B00 03 23](https://bmwtechinfo.bmwgroup.com/sib_attachments/B00%2003%2023h.pdf). It supersedes the former B58B30M1-family photo. The European left-hand-drive xDrive40i catalogue type is **21EU**. The 50e and M60i are separate powertrains.

Checked 8 September 2026: the requested [Leebmann engine collection](https://www.leebmann24.com/de/en/collection/bmw-spare-parts-engine-10032) returned HTTP 403 / Cloudflare in both direct downloading and a normal browser. No images were obtained from Leebmann. The accessible [KOED engine group](https://www.koedbmw.com/en-dk/catalog/group/21EU/11?steering=L&transmission=A) and [mounting group](https://www.koedbmw.com/en-dk/catalog/group/21EU/22?steering=L&transmission=A) supplied **all 26 BMW engine drawings and both suspension drawings listed for that type**. Retail tools and consumable advertisements were excluded. One matching donor rear photograph supplements them. The engine has 28 browsable images; the gearbox suspension drawing appears under Transmission.

[The image manifest](dist/references/engine/manifest.json) records every original image URL, file, SHA-256 checksum, applicability and rights. These are BMW catalogue illustrations, with the original copyright marks retained, plus a seller photograph. No redistribution license has been established. Catalogue diagrams can show shared parts and later service replacements; this collection does not establish VIN-specific part numbers or measured geometry. The engine surfaces are modelled from these references; the cutaway is a static educational reconstruction.
